Set Up GitHub Account & Repository
Where your website files will live · Estimated time: 20 min

GitHub is a free platform to store and version your website files. Every time you push a change, Cloudflare will automatically re-deploy your site.

1

Create a GitHub account — go to github.com and sign up. Use a professional username (e.g. sandeepsingh87) since it may appear in URLs.

2

Create a new repository — click the + icon → New repository. Set:

  • → Name: my-website
  • → Visibility: Public
  • → Check "Add a README file"
3

Install Git on your Mac — open Terminal and run:

bash
brew install git
💡
If you don't have Homebrew, install it first from brew.sh — it's the standard Mac package manager.
4

Configure Git with your name and email:

bash
git config --global user.name "Your Name"
git config --global user.email "your@email.com"
5

Clone the repository to your computer:

bash
git clone https://github.com/YOUR-USERNAME/my-website.git
cd my-website

Replace YOUR-USERNAME with your actual GitHub username.

6

Create your first HTML file. Open VS Code in the project folder:

bash
code .

Create a new file called index.html and paste this placeholder:

html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>My Website</title>
</head>
<body>
  <h1>Coming Soon</h1>
</body>
</html>
7

Push your files to GitHub:

bash
git add .
git commit -m "Initial commit"
git push origin main
⚠️
Common mistake: Don't forget the . after git add — it means "add all files". Running git add alone does nothing.

Visit github.com/YOUR-USERNAME/my-website and confirm index.html is visible.

✅
Step 1 complete! Your code is on GitHub. You should see both README.md and index.html in your repository.
2
Deploy on Cloudflare Pages
Get a free live URL in minutes · Estimated time: 10 min

Cloudflare Pages reads your GitHub repo and publishes it to the internet automatically — every time you push new code, your site updates within 30 seconds.

1

Create a Cloudflare account at cloudflare.com → Sign up (free).

2

Go to Workers & Pages — from your dashboard, find "Workers & Pages" in the left sidebar under Compute, or click "Start building" on the home screen.

3

Create a Pages project — click Create application → at the bottom of the popup look for "Looking to deploy Pages? Get started" and click it.

ℹ️
Cloudflare's UI updates frequently. If you don't see a "Pages" tab, look for the "Get started" link at the bottom of the "Ship something new" dialog.
4

Connect GitHub — select "Import an existing Git repository" → Get started → authorize Cloudflare to access your GitHub → select your my-website repo → click "Begin setup".

5

Configure build settings — fill in the form exactly like this:

FieldValue
Project namemy-website
Production branchmain
Framework presetNone
Build commandLeave blank
Build output directoryLeave blank

Click "Save and Deploy".

6

Wait ~1 minute for deployment. You'll see log output like:

deploy log
✨ Success! Uploaded 2 files (1.70 sec)
✨ Upload complete!
Success: Assets published!
Success: Your site was deployed!

You'll get a live URL like my-website-abc.pages.dev — visit it to see your "Coming Soon" page! 🎉

✅
Step 2 complete! Your site is live on the internet at a free .pages.dev URL with global CDN and free SSL.

Buy Your Custom Domain
Get yourname.in — the only cost in this whole setup · Estimated time: 15 min

Without a custom domain, your site is at something.pages.dev. Buying a domain gives you a professional URL like yourname.in.

2

Search for your desired domain name (e.g. yourname.in). Try a few variations until you find one that's available and affordable.

3

4

Complete purchase. After payment, Hostinger will show a dashboard. Look for any "Finish domain registration" prompt and complete it — .in domains require contact verification.

✅
Step 3 complete! You own a domain. Now let's point it to your Cloudflare Pages site.
4
Connect Domain to Your Site
Point yourname.in to Cloudflare Pages · Estimated time: 30 min + up to 2 hrs propagation

This step has two parts: (A) add your domain to Cloudflare, and (B) update the nameservers in Hostinger to point to Cloudflare.

Part A — Add domain to Cloudflare

1

In Cloudflare dashboard → Workers & Pages → click your my-website project → click the "Custom domains" tab.

2

Click "Set up a custom domain" → type your domain (e.g. yourname.in) → Continue → you'll see a "Transfer DNS management" screen → click "Begin DNS transfer".

3

On the next screen, type your domain in the field, keep "Import DNS records automatically" selected, and click Continue.

4

Select the Free plan ($0) — it has everything you need: DDoS protection, free SSL, global CDN.

5

Review the DNS records Cloudflare found. Click "Continue to activation". On the next page, Cloudflare will show you 2 nameservers. Copy them — they'll look like:

nameservers
kianchau.ns.cloudflare.com
linda.ns.cloudflare.com

Keep this Cloudflare tab open. Open a new tab for Hostinger.

Part B — Update nameservers in Hostinger

6

Go to hpanel.hostinger.com → Domains in the left sidebar → click your domain → click DNS / Nameservers.

7

Find the Nameservers section. Click Change Nameservers and replace the existing ones with your two Cloudflare nameservers. Save.

ℹ️
You'll see a confirmation popup saying "Nameservers changed!" with the two Cloudflare nameservers listed. This is correct.
8

Go back to the Cloudflare tab and click "I updated my nameservers". Cloudflare will begin verifying.

⏱️
Wait time: DNS propagation typically takes 10 min – 2 hours. In rare cases up to 24 hours. You'll get an email from Cloudflare when it's done: "Cloudflare's network is now boosting your domain's speed and security."
9

Once you receive the activation email, go back to Cloudflare → Workers & Pages → your project → Custom domains → "Set up a custom domain" → type your domain again → Continue → "Activate domain".

You should see your domain with a 🟢 Active status and SSL enabled.

🎉
Step 4 complete! Your custom domain is now live and pointing to your Cloudflare Pages site — with free SSL and global CDN.
