# QE Repository content

HTML resources for the [QE Repository](../qe-repository.html) — training, case studies, templates, and playbooks for Quality Engineers.

## Add a resource

1. Copy `_resource-template.html` to a new file in this folder.
2. Edit `<main>` and SEO tags in `<head>`.
3. Register it in `../qe-repository-data.js`.
4. See **[../MAINTENANCE.md](../MAINTENANCE.md)** for the full workflow.

Files here can also be linked from `sessions/` if the content already lives there — use the path in `file:` (e.g. `sessions/playwright-guide.html`).
